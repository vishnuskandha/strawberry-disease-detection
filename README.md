Train a YOLOv8 object detection model to identify seven strawberry diseases from images, then run inference on new images with a CLI script, a Streamlit app, or a browser-based demo.

Diseases covered: Angular Leafspot, Anthracnose Fruit Rot, Blossom Blight, Gray Mold, Leaf Spot, Powdery Mildew Fruit, Powdery Mildew Leaf.

## Features

- End-to-end pipeline: LabelMe annotation conversion, training, and inference
- YOLOv8n base model with automatic training resume from the last checkpoint
- Three inference interfaces:
  - CLI script (`detect_strawberry.py`) — no web server required
  - Streamlit app (`app.py`) — upload and analyze in the browser
  - Static web demo (`index.html` / `web_demo.html`) — deployable to GitHub Pages
- Windows one-click helpers: `train_yolov8.bat`, `detect.bat`, `all_in_one.bat`, `clean_repo.bat`
- Healthy vs. Not Healthy verdict based on whether any disease is detected

## Dataset

Training data is the [Strawberry Disease Detection Dataset](https://www.kaggle.com/datasets/usmanafzaal/strawberry-disease-detection-dataset) by Usman Afzaal on Kaggle. It consists of strawberry images annotated in LabelMe JSON format (polygon annotations) split into `train/`, `val/`, and `test/`. Please review the dataset license on Kaggle before use.

## Quickstart

### 1. Install dependencies

Python 3.10–3.12 is recommended.

```bash
pip install -r requirements.txt
```

### 2. Convert annotations to YOLO format

The converter reads LabelMe `.json` files from `train/`, `val/`, and `test/`, copies the matching images, writes YOLO labels under `yolo/`, and generates `dataset.yaml`.

```bash
python tools/convert_labelme_to_yolo.py
```

Note: `dataset.yaml` is regenerated by the converter and contains an absolute path to the `yolo/` folder. If you move the repository, re-run the converter (or edit the `path` field) before training.

### 3. Train the model

```bash
python train_yolov8.py
```

Or on Windows, double-click `train_yolov8.bat` (prints a simple progress/ETA message based on the previous run).

- Uses `yolov8n.pt` as a lightweight starting point
- Outputs checkpoints and logs to `runs/detect/yolov8n-strawberry/`
- Training auto-resumes when `runs/detect/yolov8n-strawberry/weights/last.pt` exists
- Tune `epochs` and `imgsz` at the top of `train_yolov8.py`

### 4. Run inference

CLI (recommended — no web server):

```bash
python detect_strawberry.py "path\to\image.jpg"
# or interactively:
python detect_strawberry.py
```

On Windows, `detect.bat "path\to\image.jpg"` does the same.

Streamlit app:

```bash
streamlit run app.py
# open http://localhost:8501
```

The detection script loads the trained model, prints a HEALTHY or NOT HEALTHY result per image, and saves an annotated copy with bounding boxes as `<name>_detected.<ext>` next to the input image.

### One-click everything (Windows)

```bat
all_in_one.bat
:: or pass an image to detect at the end
all_in_one.bat "path\to\image.jpg"
```

This installs dependencies, converts annotations, trains (resuming if a checkpoint exists), and runs detection on a sample or provided image.

### Cleanup

```bat
clean_repo.bat
```

Safely removes training outputs (`runs/`, `yolo/`), Streamlit cache, `__pycache__/`, and weight artifacts (`*.pt`, `*.onnx`, `*.engine`, `*.tflite`) without touching source code.

## Web demo

A static demo lives in `index.html` (landing page) and `web_demo.html` (drag-and-drop upload with visual preview). It runs fully in the browser and simulates detection results for illustration — for real detection use the Python scripts above.

Open it locally:

```bash
start web_demo.html
```

or deploy to GitHub Pages (push to `main` triggers `.github/workflows/pages.yml`). Live: <https://vishnuskandha.github.io/strawberry-disease-detection/>

## Troubleshooting

- Conversion fails: every LabelMe `.json` must contain `imagePath`, `imageWidth`, `imageHeight`, and `shapes`. The converter falls back to `<json-stem>.jpg` when `imagePath` is missing.
- Slow training: reduce `epochs` or `imgsz` in `train_yolov8.py`, or use a CUDA GPU.
- Fresh start: delete `runs/detect/yolov8n-strawberry/` to remove old checkpoints and logs before re-training.
- `pip` warning from an OpenCV package: `pip install opencv-python-headless` to quiet the GUI-backend message.
